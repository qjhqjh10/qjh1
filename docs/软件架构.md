# AI写作软件—青剑 v9.5.1 — 软件架构

## 技术栈

- Electron 29 + React 18 + TypeScript 5
- Zustand (状态管理) + immer + persist
- TipTap (富文本编辑器) + Tailwind CSS + Framer Motion
- OpenAI 兼容 API + Anthropic Messages API（双协议）
- DeepSeek API + Embedding（知识库语义搜索）
- G6 (关系图) + electron-builder (打包)
- Vitest (520 测试) + TypeScript严格模式

## V4 Agent 引擎

### 运行时 (`src/agent/`)
V4 用**单一 while 循环**替代了 V3 的 13 态 FSM + TaskPipeline + PlanEnforcer + ReflectionEngine + HallucinationDetector + BudgetManager + CheckpointManager + CircuitBreaker（全部删除）。模型是唯一的决策者。

| 文件 | 职责 |
|------|------|
| `V4AgentRuntime.ts` | OpenAI 协议 Runtime — while 循环驱动（API → tool_calls → 执行 → 继续） |
| `V4AnthropicRuntime.ts` | Anthropic 协议 Runtime — 流式 content blocks 循环 |
| `V4AgentChatBridge.ts` | OpenAI Bridge — 整合 Runtime + SecurityFence + AuditTrail + LearningEngine |
| `V4AnthropicChatBridge.ts` | Anthropic Bridge — 同上, 独立实现 |
| `ChatBridgeInterface.ts` | 共享接口 + 协议工厂（根据配置自动选择 Bridge） |
| `V4SystemPrompt.ts` | 系统提示词 — CORE_PROMPT + 10 领域模块 + 动态选择 |
| `V4SecurityFence.ts` | 三层安全围栏 — 硬拦截(系统路径/UNC/环境变量) / JSON 校验 / 外部路径审批 |
| `IntentClassifier.ts` | 意图分类器 — chat/simple/complex + 要求数统计（轻量 API 调用） |

### 运行时特性
- **上下文压缩** — 透明压缩, 保护最近消息 (H10), Claude 风格 staging
- **渐进工具展开 (v4.1)** — iteration 1-2 核心工具, iteration 3+ 追加扩展工具, 最后一轮移除所有工具
- **API 重试** — 瞬态错误 (timeout/429/503) 自动重试 1 次, 指数退避
- **并行读/串行写** — 只读工具 (AUTO/READ_ASK) 并行执行, 写入工具顺序执行
- **合同执行器** — 工具结果过滤, iteration>1 渐进裁剪到 500 字
- **空响应兜底 (H5)** — 模型返回空文本 + 无工具 → 注入提示重启
- **轮次提示** — iteration 3+ 注入"第N轮"提示, 最后轮注入 "[最后轮次]"

## 数据流

```
用户操作 → React 组件 → service → IPC → Electron main process → 文件系统/外部API
                              ↑
                     preload (contextBridge) 安全隔离

Agent 执行: V4AgentRuntime while 循环
  → ContextAssembler 组装上下文 (10 Provider + 全局索引 + 知识库 + 联网搜索)
  → AI API 调用 (OpenAI 或 Anthropic 协议)
  → 工具执行 (三层安全围栏: 硬拦截 → JSON 校验 → 路径审批)
  → 结果反馈 (ContractExecutor 过滤 → 渐进裁剪)
  → LearningEngine 学习

Agent UI 实时反馈:
  AgentStateBar (阶段+迭代+token) + AgentThinkingPanel (思考过程)
  + ToolExecutionCard (工具进度) + 流式文本气泡 + DiagnosticPanel
```

## 核心功能流程

**小说创作**: 创建项目 → 大纲 (10Tab) → 细纲 (卡片拖拽) → 场景工坊 → 风格工坊 → 角色管理 → 章节创作 (编辑器+AI) → 知识库 → 故事脉络 (14Tab) → 导出 EPUB/TXT

**小说仿写**: 导入 TXT → 类型选择 (17 种) → 维度选择 → 逐章提取 → 聚合 → 风格分析 (26 维) → 大纲模仿 → 细纲模仿 → 三栏编辑器写作

**小说续写**: 导入 TXT → 逐章分析 → 原作理解 → 剧情走向 → 大纲融合 → 续写细纲 → 续写章节 (7 步向导)

**设置页**: 模型配置 (10+ 服务商) + 提示词库 + 青剑助手 (Agent Tab) + 显示设置 + Token 统计 + 版本信息

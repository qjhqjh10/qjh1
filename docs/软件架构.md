# AI写作软件—青剑 v14.0.2 — 软件架构

## 技术栈

- Electron 29 + React 18 + TypeScript 5
- Zustand (状态管理) + TipTap (富文本编辑器) + Tailwind CSS
- DeepSeek API (Anthropic + OpenAI 双协议)
- Vitest (457 passed + 15 skipped，共 472 用例)

## v14.0.0 架构变化

- **双 Bridge 合并**: V4AgentChatBridge/V4AnthropicChatBridge 主体收敛到 `src/agent/chatBridgeFactory.ts` 的 `BaseChatBridge`（抽象方法参数化 adapter/abort/runId/thinking），两文件缩为协议差异薄包装
- **共享拖拽 hook**: `src/components/common/useDraggableResizable.ts`（left-top/right-bottom 双锚定 + 8 手柄 + 持久化），接入 PopupWindow/useWindowDrag/AISettingsTab×3/PromptLibraryTab
- **知识库设置**: `aiSettings.kbSettings` 分场景（agent/generation），设置页新增 KnowledgeBaseSettingsTab；KB 检索/注入不再要求项目内（electron kb:search projectId 为空 → 全部文件）
- **角色自定义条块**: `Character.customBlocks: {label, content}[]`，AI 生成未知字段自动吸收；schemaValidation 角色字段同步为 14 字段
- **删除**: ThinkingEngine.ts、shellHandlers.ts、RelationshipGraphModal/graphRenderer/useRelationshipGraph（关系图）、润色菜单项

## v14.0.2 架构变化

- **系统提示词唯一来源**: 删除 `.aiharness/prompts/CORE_SYSTEM_PROMPT.md`（v13.2 瘦身前旧版，15 字段/内嵌 12 节手册与代码分叉）与 `app:getSystemPrompt` IPC 链（main.ts/preload/electron.d.ts）；`buildSystemPrompt()` 同步直接返回代码内 `CORE_SYSTEM_PROMPT`（V4SystemPrompt.ts）。修复开发环境用旧版 MD、打包环境用新版 TS 的行为不一致

## 上下文注入架构 (v13.2.0)

```
每轮注入:
  system[0]: 核心规则 (~3,600 tokens, System Prompt 瘦身后)
  system[1]: 角色模板 (可选，固定前缀)
  tools:     首轮 27 个，后续 12 核心 + tool_search 动态发现

System Prompt 从 ~5,800 tokens 瘦身到 ~3,600 tokens (写作规范手册 12 节→7 个外部模板文件)。
Prompt 缓存 (DeepSeek 前缀缓存 + Anthropic cache_control) 减免固定开销费用 90%+。

BridgeContextBuilder 负责：
  - 核心规则 (始终全量)
  - 角色模板注入
  - KB 搜索 + Web 搜索 (动态)
  - 项目信息注入
  - Token 估算

ContextCompressor: 3 阶段渐进压缩 (70%/80%/90%)
cleanOldReadResults: 超过 5 轮 read_file 结果压缩
ContractExecutor: 写工具去 detail

上下文进度条: 使用 estimatedContextTokens (基于 messagesForApi 真实大小)
```

## 核心功能

- **小说创作**: 大纲(10Tab) → 细纲 → 章节写作(编辑器+AI生成+风格/场景模板注入)
- **小说仿写**: 导入TXT → 13种类型 → 逐章提取 → 聚合 → 风格分析 → 大纲/细纲模仿
- **小说续写**: 导入TXT → 13维度逐章分析 → 原作理解 → 续写章节 (7步)
- **章节生成**: 四层提示词(风格→剧情→场景→参考) + 流式输出 + 温度调节
- **风格/场景工坊**: 模板创建和管理
- **故事脉络**: 多维度分析 + 冲突检测
- **知识库**: PDF/DOCX/TXT → 语义搜索
- **导出**: EPUB 3.0
- **设置**: 多模型管理 + Token统计 + 双协议切换 + 角色模板
- **对话测试**: 22 场景 (19 原有 + 2 角色扮演 + 1 渐进披露)

# AI写作软件—青剑 v9.5.1 — 软件架构

## 技术栈

- Electron 29 + React 18 + TypeScript 5
- Zustand (状态管理) + immer + persist
- TipTap (富文本编辑器) + Tailwind CSS + Framer Motion
- OpenAI 兼容 API + Embedding (知识库)
- G6 (关系图) + electron-builder (打包)
- Vitest (380 测试) + TypeScript严格模式

## 数据流

```
用户操作 → React组件 → service → IPC → Electron main process → 文件系统/外部API
                              ↑
                     preload (contextBridge) 安全隔离

Agent执行: AgentRuntime FSM循环
  → ThinkingEngine解析计划 → ContextAssembler组装上下文
  → AI API调用 → 工具执行(5层安全检查) → 结果反馈
  → SkillLearner/LivingSkill学习 → 评估管道 → 反馈闭环

Agent UI实时反馈: startRun/endRun激活 → AgentStateBar(阶段+迭代) + AgentThinkingPanel(思考计划) + ToolExecutionCard(工具进度) + 流式文本气泡 + Hook指示器
```

## 核心功能流程

**小说创作**: 创建项目 → 大纲(10Tab) → 细纲(卡片拖拽) → 场景工坊 → 风格工坊 → 角色管理 → 章节创作(编辑器+AI) → 知识库 → 故事脉络(14Tab) → 导出EPUB/TXT

**小说仿写**: 导入TXT → 类型选择(11种) → 维度选择 → 逐章提取 → 聚合(6模式) → 风格分析(26维) → 大纲模仿(7维) → 细纲模仿 → 三栏编辑器写作

**小说续写**: 导入TXT → 逐章分析 → 原作理解 → 剧情走向 → 大纲融合 → 续写细纲 → 续写章节(7步向导)

**Agent设置页**: 设置→Agent Tab → 8子Tab: 概览(6指标+断路状态+趋势) / 指标(会话列表+工具排行+趋势) / 技能(LivingSkill阶段分布+已学习规则) / 反馈(auto-suggestions.md解析) / 可靠性(断路器+检查点+会话) / 健康(GCAgent扫描) / 团队(5子Agent+Relay说明) / MCP配置

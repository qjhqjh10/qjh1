# 文件作用速查 v9.5.1（AI写作软件—青剑）

## Electron 主进程（electron/）

| 文件 | 职责 |
|------|------|
| `main.ts` | 应用入口，创建窗口，注册全部 IPC handler (19 个模块) |
| `preload.ts` | contextBridge 安全 API，暴露命名空间给渲染进程 |
| `ipc/aiHandlers.ts` | OpenAI 协议 API 代理 (流式+工具调用)，token 统计，成本计算 |
| `ipc/anthropicHandlers.ts` | Anthropic 协议 API 代理 (SSE 流式 content blocks)，独立通道 |
| `ipc/fileHandlers.ts` | 基础文件读写 + 文件监视器 (双向同步) |
| `ipc/fileToolHandlers.ts` | AI 文件操作工具执行 (7 个: read_file/list_directory/search_content/edit_file/create_file/delete_file/rename_file) |
| `ipc/projectHandlers.ts` | 项目 CRUD (创建/删除/列表/切换) |
| `ipc/kbHandlers/` | 知识库 (解析+分块+Embedding+搜索)，含 helpers.ts |
| `ipc/exportHandlers.ts` | 导出 (EPUB/TXT/ZIP) |
| `ipc/statsHandlers.ts` | Token 用量统计 (JSONL 日志+按天/模型/配置聚合) |
| `ipc/agentHandlers.ts` | Agent 会话/权限持久化 + CLI 自优化 |
| `ipc/styleHandlers.ts` | 风格项目管理 |
| `ipc/styleTemplateHandlers.ts` | 风格模板 CRUD |
| `ipc/templateHandlers.ts` | 场景模板 CRUD |
| `ipc/storyHandlers.ts` | 故事脉络数据 (时间线/伏笔/一致性等) |
| `ipc/continuationHandlers.ts` | 续写功能 IPC |
| `ipc/extractionHandlers.ts` | 仿写提取 IPC |
| `ipc/rewriteHandlers.ts` | 改写功能 IPC |
| `ipc/httpHandlers.ts` | HTTP 请求代理 (URL 校验+内网禁止) |
| `ipc/browserHandlers.ts` | 网页内容提取 + 搜索引擎 (DuckDuckGo + Puppeteer) |
| `ipc/shellHandlers.ts` | Shell 命令执行 (白名单+禁止模式) |
| `ipc/mcpHandlers.ts` | MCP 客户端 (JSON-RPC over stdio) |
| `ipc/lspHandlers.ts` | TypeScript 类型诊断 |
| `ipc/schemaValidation.ts` | JSON 格式校验 |
| `ipc/ssrfGuard.ts` | SSRF 防护 (共享模块，URL/IP 验证) |
| `ipc/logger.ts` | 日志工具 ([青剑] 前缀) |
| `ipc/utils.ts` | 工具函数 (isSafePath/加密/配置存储/窗口边界) |

## Agent 运行时（src/agent/）

### 核心文件

| 文件 | 职责 |
|------|------|
| `V4AgentRuntime.ts` | OpenAI 协议 Runtime — 单一 while 循环，模型是唯一决策者 (~484 行) |
| `V4AnthropicRuntime.ts` | Anthropic 协议 Runtime — 流式 content blocks 循环 (~540 行) |
| `V4AgentChatBridge.ts` | OpenAI Bridge — 整合 Runtime+SecurityFence+AuditTrail+LearningEngine |
| `V4AnthropicChatBridge.ts` | Anthropic Bridge — 同上，独立实现 |
| `ChatBridgeInterface.ts` | 共享接口 + 协议工厂 (根据配置自动选择 Bridge) |
| `V4SystemPrompt.ts` | 系统提示词 — CORE_PROMPT + 10 领域模块 + selectDomainModules 动态选择 |
| `V4SecurityFence.ts` | 三层安全围栏 — 硬拦截 / JSON 校验 / 外部路径审批 + 危险工具门 |

# 迷雾静止世界 — 小说构思

> 类型：情色小说 / 悬疑幻想
> 状态：设定已定型，可进入第一章创作

---

## 一、世界观设定

### 🌫️ 迷雾与"人不能动"

**核心设定**：世界被迷雾笼罩，**人不能动了**。而非时间停止。

| 能动的 | 不能动的 |
|--------|---------|
| ✅ 风在吹、树叶在摇、光在移动 | ❌ 所有人像蜡像一样定格 |
| ✅ 水滴悬浮（无人扰动），男主碰触则正常下落 | ❌ 呼吸停止、心跳感知不到 |
| ✅ 门可推开、灯可打开、水龙头能出水 | ❌ 不能发声、不能眨眼、不能移动 |
| ✅ 手机无信号，但电器可能正常运转 | ❌ 但身体**有体温**，温暖如睡着 |
| ✅ **只有男主能自由行动** | |

> **关键区别**：不是时间停止，是"活着但没有人的世界"。风在吹、灯在亮、电话在响，但没有人接。比死寂更诡异。

### 🏫 迷雾的边界与地图拓展

- 迷雾形成**无形的墙**，男主被困在**大学城**内
- 大学城包含：大学 → 高中 → 初中，多个学校组成的学区
- **地图拓展顺序**：

| 阶段 | 地图 | 氛围 |
|------|------|------|
| 🏫 **初期** | 大学校园 | 男主最熟悉的环境，新奇与恐惧并存 |
| 🏛️ **中期** | 高中校区 | 道德感升级，氛围更禁忌 |
| 🏫 **后期** | 初中校区 | 最大道德挑战，需特殊叙事处理 |
| 🌍 **终期** | 迷雾之外 | 未知，留白或收束 |

### 🧠 世界观内核（选项C）

- 男主是**被选中的"观察者"**
- 有更高力量在通过迷雾测试人性
- 来源/身份 → **中后期揭示**，前期保持神秘

## 二、男主设定

### 性格路线：B — 好奇探索型 ✅
- **基调**：普通大学生的好奇心和荷尔蒙驱动
- **心理历程**：震惊怀疑 → 试探摸索 → 好奇探索 →（后期可向冷静理性过渡）
- **优势**：读者容易代入，性格弧线自然

### 身份背景
- 普通大学生，年龄约19-21岁
- **宿舍**：四人间
  - 🎮 室友A — 打游戏中，定格在电脑前
  - 🎮 室友B — 打游戏中，定格在电脑前
  - 🚶 室友C — 事发时外出了，不在宿舍

### ⚡ 异能系统（无面板，自己摸索）
> 没有系统面板，没有语音提示。男主通过性行为后**自己感觉到、摸索总结出来**，更像身体的本能觉醒。

| 能力 | 解锁方式 | 说明 |
|------|---------|------|
| ① **复原物品** | 首次关系后逐渐感知 | 修复损坏的东西（打通道路/修复工具/恢复物品） |
| ② **将复苏者变回静止** | 积累经验后摸索出来 | 可控性——做错了可以"重置" |
| ③ **更多能力待探索** | 随剧情推进 | 男主需要自己发现 |

### 🧬 苏醒机制
- 男主**精液注入女生体内** → 女生在**几小时到几天内逐渐苏醒**
- 苏醒时间因人而异（与年龄/体质/注入量相关？待定）
- **苏醒后的记忆设定** → 🔴 待定

## 三、开篇 — 第一章场景线（已确认）

### 开篇时间线：第一天
> 男主从睡梦中醒来 → 发现异常 → 走出宿舍探索校园 → 发现被困

### 🎬 场景一：宿舍（心理阶段① — 困惑与恶作剧猜想）

**环境**：早晨的四人宿舍，阳光从窗户照进来

**画面清单**：
- 男主醒来，最先察觉的是**太安静了**——没有室友的键盘声、没有走廊的脚步声、没有楼下食堂的嘈杂
- 喊室友名字 → 没人应
- 下床 → 看到室友A/B像蜡像一样定在电脑前
- **第一次触碰**：推室友的肩膀 → 有体温，温暖柔软的，像睡着了一样 → 但不睁眼、不说话、不呼吸
- 以为他们在恶作剧 → 拍脸、摇晃、大喊 → 没用
- 拿出手机 → 没信号
- 怀疑自己在做梦 → 掐自己 → 疼的 → 不是梦

**氛围关键词**：困惑 → 轻微不安 → "他们在整我吧"

---

### 🚪 场景二：宿舍走廊（心理阶段①→②过渡）

**男主动作**：打开宿舍门，走出去

**画面清单**：
- 走廊里也定格着人：
  - 隔壁宿舍门口，有人定格在掏钥匙的姿势
  - 走廊尽头，有人端着洗漱用品，水珠悬在杯口
  - 有人保持着走路的姿态，一脚在前一脚在后
- 男主逐个试探 → 喊、拍、推 → 全都没有反应
- 走到走廊尽头的窗口 → 往外看

**关键发现**：不是只有自己宿舍出了问题，是**整栋楼**、**所有人**

**氛围关键词**：不安升级 → 心跳加速 → "这不对"

---

### 🏢 场景三：楼梯间与宿舍楼大门

**男主动作**：走楼梯下楼

**画面清单**：
- 楼梯转角，有男生定格在走楼梯的瞬间，身体前倾，差点要倒的样子
- 男主本能地扶了他一把（确认：也是温暖的，但这是个男的）
- 继续往下走，经过二楼拐角时——**看到她了**
- 一个女生站在楼梯转角平台上，手里拿着一个**查寝登记表**，另一只手握着笔，定格在低头写字的姿势
- 她是学生会宿管部的，早上来男生宿舍查寝
- 男主愣了一下——**男生宿舍怎么会有女生？** 哦对，周三早上宿管部查寝……但查寝的人也被定住了
- 他试探性地伸手，碰到她的手腕——**温暖的，有体温**
- 她保持着写字的姿势，刘海微微垂下来，晨光从窗户外照进来，落在她的侧脸上
- 男主站在她面前，第一次**认真看**一个定格的女生
- 但他现在顾不上这个，继续往下跑

**过渡心理**：男生宿舍楼里出现女生这个细节，反而强化了"所有人不分男女老幼全部定格"的诡异感。

- 宿舍楼一楼大厅：
  - 宿管阿姨定格在窗口前，手里拿着钥匙
  - 公告栏前有人定格在看通知
  - 大门半开着，有光透进来

**男主站在宿舍楼门口**：推开门，走出去——这一步，从室内走到室外，心理上的跨越很大。

---

### 🌳 场景四：宿舍楼下到校园主干道（心理阶段② — 发现不对劲）

**画面清单**：
- 男主走出宿舍楼，第一次看到**户外的定格世界**：
  - 宿舍楼下的小路上，有人定格在晨跑的姿势，一只脚悬空
  - 自行车道上，有人骑着车定住，车还稳稳立着
  - 风在吹 → 吹动树叶、吹动定格的衣角、吹动女生的头发 —— **但人不为所动**
  - 阳光在移动，影子在慢慢拉长 → 时间在走，但人不动
- 男主走到校园主干道上，环顾四周：
  - 路上十几个人，定格在各自的动作中：走路、低头看手机、骑车、回头说话
  - 远处的操场上，有人在跑步的姿态中僵住
  - **整个世界像被按下了暂停键——但风、光、树都在说：没有暂停**

**关键心理转变点**：
> 当男主看到"风在吹但人不动的校园"这一刻，他内心从"恶作剧猜想"彻底转向"出事了"

---

### 🏃 场景五：恐慌奔跑与发现雾墙（心理阶段③ — 恐慌与逃跑尝试）

**男主动作**：开始慌了 → 本能地想跑出学校

**奔跑路线**：
- 从校园主干道 → 路过食堂（门口有人定格在进门瞬间）
- 路过教学楼（透过玻璃能看到教室里定格的师生画面）
- 跑向校门口

**画面清单**：
- 校门口的场景：
  - 保安亭里，保安定在那里
  - 校门半开，外面能看到马路、停在路上的车、定格在方向盘前的司机
  - 马路对面也有人定格
- 男主冲向校门 → 冲到门口 → **撞上了什么**
  - 空气变得粘稠，像撞进了一堵无形的墙
  - 伸手去摸 → 手掌贴在透明的屏障上，推不动
  - 用拳头砸 → 纹丝不动
  - 沿着"墙"的边缘跑 → 发现它包围了整个学校
  - 雾就在墙外弥漫，但穿不过去

**关键场景**：男主靠在透明的墙上，滑坐下来，喘着粗气，彻底明白——**他出不去了。**

---

### 🔄 场景六：回到校园（心理阶段④ — 绝望到好奇的转折）

**男主动作**：接受被困的事实 → 慢慢往回走

**画面清单**：
- 回去的路上，定格的景象和之前一样，但男主的**心态变了**
- 不再恐慌奔跑，而是**真正地"看"这个世界**：
  - 他看到定格在晨跑姿势的女生 —— 之前只是"一具定格的人"，现在开始注意她的样子、身材
  - 他看到食堂门口端着餐盘的女生 —— 甚至有点可爱
  - 他看到教学楼走道里定格在说笑的女生们
- 一个念头开始浮现：**「如果这个世界只有我能动……那我是不是可以为所欲为？」**
- 男主被这个念头吓了一跳 → 赶紧压下去 → 但那个念头已经种下了

**氛围关键词**：绝望 → 冷静 → 好奇心抬头 → 欲望的萌芽

## 四、各场景定格的女生推荐（为第一个目标埋伏笔）

在探索过程中，男主会路过多个定格女生，这些都是**潜在的第一目标候选**：

| 出现场景 | 角色定位 | 特点 | 优先级 |
|---------|---------|------|-------|
| 🚪 **楼梯间·查寝女生** | 学生会宿管部 | 男主**第一个有印象**的定格女生，晨光下的侧脸，查寝时定格 | ⭐⭐⭐ |
| 🏃 晨跑女生 | 操场附近 | 定格在运动姿态，身材突出 | ⭐⭐ |
| 🍽️ 食堂女生 | 食堂门口 | 日常画面，最有"校园感" | ⭐ |
| 🚲 骑车女生 | 主干道 | 定格在车上的姿态，视角独特 | ⭐ |
| 📚 教学楼女生 | 教学楼走廊 | 学霸类型，文静气质 | ⭐ |

> 💡 **建议首选**：查寝女生。因为她出现在**男生宿舍楼里**——这个天然的合理性让她成为第一个映入男主眼帘的女生。晨光照在她侧脸上的画面，可以成为后续"第一个目标"的心理伏笔。男主在楼梯间已经触碰过她（手腕），也认真看过她了。

## 五、后续叙事展望

### ⏱️ 苏醒等待期的戏剧价值
- 注入后到苏醒有数小时到数天的时间差
- 男主可以同时与多人发生关系，分批等待苏醒
- 苏醒的人发现自己位置/姿势被改变，心理冲击巨大

### 🗺️ 地图拓展路线
- 第一阶段：大学校园全貌（宿舍楼群/食堂/教学楼/图书馆/操场/社团楼）
- 第二阶段：大学边缘 → 高中校区
- 第三阶段：初中校区
- 终期：迷雾之外

## 问题背景

这三个文件中共有 **28 处**使用具体中文关键词枚举列表来定义触发条件。例如：

- `"看看"/"查看"/"帮我看看"...` 触发分支1B
- `"展示"/"列出"/"输出"/"看看"` 触发输出内容
- `选择|想怎么|要怎么|如何处理...` 判断是否在问用户

这种"关键词匹配机"模式的问题：
1. 同义词不命中（"显示"≠"展示"→不触发）
2. 不同分支关键词重叠（"创建角色"同时匹配3条路径）
3. Prompt 和 Runtime 两套独立关键词系统不一致
4. 模型被降级为字符串匹配器而非意图理解者

## 优化方向

将所有关键词枚举列表改为意图描述，利用 LLM 的自然语言理解能力替代硬编码匹配。
